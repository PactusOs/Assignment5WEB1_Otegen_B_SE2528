# Assignment 5—JavaScript Basics

Student: Beimzhan Otegen  
Group: SE-2528

Four pages cover all tasks using only HTML, CSS and JavaScript:

- `index.html` — console, alert, variables and operators (Tasks 0–1)
- `dom.html` — changing text/styles and adding/removing elements (Tasks 2–4)
- `events.html` — mouse/keyboard events and calculator (Tasks 5–7)
- `todo.html` — add, complete and delete tasks stored in a JavaScript array (Task 8)

## Run

Open `index.html` in a browser and use the navigation bar to switch pages. Press F12 and open the Console to inspect Tasks 0–1.

## Publish with GitHub Pages

1. Create a GitHub repository and upload these files to its root.
2. Open **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
3. After deployment, submit both the repository URL and the published website URL as required by the assignment.
